# Retired

This template is no longer maintained. To start a Cassis ontology on your own schema, use the
[cassis-demo-stallora](https://github.com/GetCassis/cassis-demo-stallora) template and replace the
`cassis/` tree with your own; it carries the same CI gates, MCP config and modeling guide. For a
minimal tree to copy, see [cassis-ontology-examples](https://github.com/GetCassis/cassis-ontology-examples).
